# FoodWise Flutter app

Flutter SDK required. Flutter platform boilerplate is generated by `flutter create`, not bundled here.

```bash
# From the starter root:
flutter create foodwise_mobile
# Copy supplied files under mobile/lib/ into foodwise_mobile/lib/
cd foodwise_mobile
flutter pub add http
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

Use `http://127.0.0.1:8000` with an iOS simulator (where supported), or `http://YOUR_COMPUTER_LAN_IP:8000` for a physical Android/iOS device. On physical devices run Uvicorn with `--host 0.0.0.0`, allow firewall access, and use the same Wi-Fi network. For Android development HTTP you may need `android:usesCleartextTraffic="true"` in the debug manifest's application element. Add `<uses-permission android:name="android.permission.INTERNET"/>` to AndroidManifest.xml. Production requires HTTPS.

This simple app holds the JWT in memory only; closing the app logs out. Production should use securely stored credentials with token refresh and proper error handling.
